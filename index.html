반자동 색인 편집기 1.11

made by 원더박스 곽편 — 사용법 안내
1
상단 PDF 열기로 원고 파일을, 색인 파일 열기로 색인 텍스트 파일을 불러옵니다.
2
검색창(Ctrl/Cmd+F)에 키워드를 입력하고 Enter를 누르면 PDF에서 해당 키워드가 있는 페이지를 찾습니다.
3
오른쪽 색인어를 클릭하면 현재 PDF 페이지 번호가 해당 색인어에 자동 삽입되고, 다음 검색 결과 페이지로 이동합니다.
4
←→ 앞/뒤 페이지   ↑↓ 검색 결과 이동   색인어 꾹 누르기 → PDF 검색   우클릭 → 추가 메뉴
5
작업 완료 후 💾 내보내기로 색인 파일을 저장합니다. Cmd+Z로 모든 작업을 되돌릴 수 있습니다.
